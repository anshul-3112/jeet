## 🚀 Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (v4)
- **Routing**: React Router DOM (v6)
- **Icons**: Lucide React
- **SEO**: LocalBusiness & Service Schema.org JSON-LD, Dynamic Meta tags, OpenGraph

---

## 📋 Features

1. **20+ Document & E-Governance Services**:
   - Identity & Travel (Aadhaar, PAN, Passport, Driving Licence, Smart Card EPIC/Aadhaar)
   - Government Certificates (Caste Validity with full brochure checklist, Caste Certificate, Income, Domicile, EWS, Non-Creamy Layer / Central Caste)
   - Business & Legal (Gumasta Shop Act, FSSAI Food Licence, Gazette, Affidavits, Registered Rent Agreement, MSEB, Loans, Insurance, Online Admission & Recruitment Forms)
2. **Lead Generation & WhatsApp Integration**:
   - Contextual pre-filled WhatsApp links across all service cards and enquiry forms.
   - Sticky mobile bottom CTA bar (`[ 📞 Call 8055203555 ] [ 💬 WhatsApp ]`).
   - 4-field quick enquiry form with pre-selected service routing to `/thank-you`.
3. **Bilingual Ready**:
   - Instant English ↔ मराठी toggle with persistent language preferences.
4. **Interactive Document Checklist**:
   - Checkboxes and "Copy Checklist" button for citizens to prepare their papers.
